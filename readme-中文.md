# 拾碎-懒人桌面工具箱（DeskBits）v0.99-R052

一款 Windows 桌面图标整理 + 系统小工具箱：按分类一键切换桌面图标、彩色
高亮框标记、文件夹组一键打开、布局记忆与使用统计，另带锁屏、条件监视、
事件查看器（大白话）、计划任务、一键维护等系统工具。纯本机运行，
不上传任何数据。

## 主要功能

### 🖼️ 桌面图标整理（核心）

- **图标分类**：自定义分类（程序/网络/工作/英语…），把图标拖入或按名称归类
- **一键切换**：顶部悬浮条点击分类名，桌面立即只显示该分类的图标，其余隐藏
- **悬浮条外观**：底色随主题由上到下渐变、顶边一道高光线（不再是死板的纯色块），
  渐变浓淡做成**三档自己拨**（设置页→悬浮栏卡→「悬浮栏渐变」：朴素 / 微渐变 / 明显），
  默认给到最浓的"明显"（顶浅底深差约 132 级亮度），嫌花的可以退回"微渐变"（约 66 级，
  就是以前那一档）或"朴素"（约 25 级，看着接近纯色）；换档当场生效，重启照读你上次拨的，
  分类色点与胶囊底色同源，换主题当场跟着变；
  **鼠标划过哪一格，那一格就抬亮一档**（顶边再描一道反光，离开自动回原样），
  一眼看清自己正 pointing 哪个分类
- **高亮框**：用彩色边框圈住当前分类的图标，7 种形状、颜色/线宽/虚线可调，
  支持按分类着色区分
- **样式跟着"方式"走**：选"分区"就能改线宽和虚实（虚线时线宽按 1px 走，这是系统的画法限制）；
  某个方式用不到的下拉会自动变灰、点不动，不再出现"选了没反应"——**★R293 起分区里每一档画法
  各自说清自己吃哪几味**：包络框 / 双线框 / 细双线框 吃 形状+线宽+样式，色块纱环 / 柔光晕 /
  细柔光晕 吃 形状+线宽，荧光笔 / 斜纹带 / 取景角 只吃线宽，角贴 一味都不吃
  （它画的是角标那枚小色点，粗细方圆归"角标"管，这条是有意留着没拆的）；
  灰掉不改你原来的选择，切回"方框"时照旧；
  **鼠标放在灰掉的下拉上会弹一句说明**（「画法=角贴 用不到 线宽：这一档它不改变画面」），
  不用猜为什么点不动
- **"框大小"这一项已经去掉**：它在所有方式下都不改变画面（历史遗留的无效选项），规则页不再摆这个下拉，
  避免"点不动还以为程序没设计好"；存档里的值照旧保留，哪天渲染侧接上还能用
- **显示方式 8 档**（规则页"高亮"区，随时可换、旧 4 档一直在）：方框 / 色块垫底 /
  文字高亮 / 聚光灯 / **分区**（挨得近的同类图标并成一块，块外挂一张分类名牌；
  **两个也并、竖着排也并**，能不能并看图标格子的实际间距，跨大半个桌面才不误并；
  **隔开几格还算一伙可以自己调**——规则页「并团」下拉四档 **挨着 / 隔1格 / 隔2格 / 隔3格**，
  档名就是"中间允许空掉几个图标的位置还算一伙"；缝以**图标格自身大小**为单位
  （换缩放自动跟着变，不用重调），而且**横排看横向格宽、竖排看纵向格高**——
  同一档在两个方向上的像素上限本来就不一样，这也是"横排跟着变"的原因：
  默认"挨着"＝中间一空就分（画面与 ★R278-C **一个像素都没变**）；"隔1格"＝空一个图标位还算一伙，
  最宽一档也只到空 3 格，够不到把半屏圈进一个框的程度；选别的显示方式时这一档是灰的，因为只有分区用得到；
  **鼠标放在这一档上会弹一句量化说明**（不用自己目测"半格是多远"）：当前档每个方向的余量是多少像素、
  四档分别多少（本机 100% 缩放实测断点：横排 39 / 113 / 188 / 263 px、竖排 39 / 173 / 271 / 369 px），
  再给两把本机尺——横排相邻两格的缝约 1px、竖排约 26px，空一格时横排约 76px、竖排约 124px，
  一看就知道哪一档会把哪几个并上；
  挤不下就只在块顶描一层淡色字，不挡图标）/
  **色块纱环**（图标四周蒙一层细色纱、中间不挡，图标和名字都看得清）/
  **荧光笔**（名字下方一道淡色带）/ **角贴**（右上角一枚小色点，最不打扰）
- **选了"分区"再多一枚「画法」十档**（规则页"高亮"区，随时可换）：包络框（默认，一圈线框住整团）/
  色块纱环 / 荧光笔 / 角贴 / 取景角（只在四角各描一块）/ 双线框（两圈线中间夹一条**真透明**的缝）/
  斜纹带 / 柔光晕（沿团边向内三条渐淡的抖动带）/ **细双线框** / **细柔光晕**——最后两档是
  "同样画法、更细一档"的预设（缝更窄、线更细、带更淡），嫌双线框或柔光晕抢眼就换它们，
  切档只换画面、不动你已经选好的颜色和线宽
- **文件夹组**：把常用的几个资源管理器窗口保存为命名组（如"英语""程序"），
  悬浮条"一键目录"或切分类时一键打开，Win11 22H2+ 自动合并为单窗口选项卡
- **布局记忆**：保存/恢复整套图标位置（手动模式：切分类或恢复布局即排好，
  拖动后点"保存"留存）
- **系统图标显隐**：此电脑/回收站/网络/控制面板随分类联动或常显/常隐；这一组勾了「不包含系统图标」的，切到它时那五枚会真的从桌面隐掉，切走时按你原来的状态还原（不会自作主张摆回"显示"）
- **排行榜显示**：按使用排行只显示前 N 名 / 第 M~N 名图标（规则页）；
  还能把第 M~N 名**建成排行组**——起个名、挑个色：勾"常驻"每次开机都在顶部条，
  **不勾也当场出现在顶部条给你看这一次**（一个字节都不写盘，重启自动消失），
  建组时默认勾着「不包含系统图标」，此电脑/回收站/网络/控制面板/用户文件夹
  这五枚不会被并进组里，**切到这一组时桌面上那五枚也一起隐掉**（想收进来取消勾选即可，↻ 刷新组也照这个口径刷）；
  点它直接只显示这批图标；**排行组排在条尾的临时区，不占你手工钉的那些槽位**
  （临时区自己封顶 6 枚，建多了只挤别的排行组，一枚分类都不会被撤；
  以前是"槽位满了就悄悄上不了栏，重启也看不见"）；
  榜单会随使用变，多一枚「↻ 刷新组」按**最新榜单**把已建好的组重新灌一遍名单
  （可只刷一组，组名不变、颜色不变）；
  同名再建（比如第二次建"排行 1-4 名"）是**覆盖更新**那一组，不再报错也不留旧名字；
  每次建组都在日志里记一行（榜源/区间/命中几个/结果），被拒也记**并写清为什么被拒**
  （空名单/保留名/写盘失败…），方便排查；
  多一枚「⛔ 撤组」当后悔药：**取消常驻**（顶部条这次还显示、重启就没了）或
  **连分类一起删**，一键做完，不用再绕去「管理」页找那条分类；两把都只认排行组自己的
  身份证，借这条路误删你手工建的分类是堵死的
- **桌面盒子（v0.99-R022 新功能）**：勾几个图标按「📥 装进盒子」，图标**真的从桌面搬走**
  （不是隐藏），盒子放在 `C:\Users\<你的用户名>\桌面盒子deskbits\<盒名>`，桌面一下清空、
  盒里随时翻；「📤 全部散回桌面」按清单原路搬回、按布局存档摆回原位——搬回来那一刻桌面
  可能还在重排，程序会等图标真正出现在桌面上（最长约 2.2 秒）再一枚一枚摆，原位被占了
  就让到最近的空位，绝不谎报"已摆好"；
  撞名 / 被占用 / 跨磁盘都会当面点名（在"资源"页）。卡是左右对称的三栏：左=桌面可收纳的、
  中间三枚动作、右=盒里现有的，两列一样宽、整张卡按内容自己收拢（不再横满整页，v0.99-R026）；
  第一行一枚下拉既能选已有盒子
  也能直接打字起新名（点「建盒子」才真建）。卡上有一枚"筛选"框，打两个字两张表同时收窄，
  表头报「匹配/总数」和"已选几枚"。卡上那枚「🔄 自动收纳」**默认开着**（★R304-3）：开着时每枚
  图标按自己现在的分类回**同名盒子**，跨分类也各回各盒、缺的盒子当场建，不用你先建盒再挑；
  还没归过类的它**一枚都不替你猜**，弹窗会把名字念出来。取消勾选就回到老规矩——一批发进
  下拉里选中的那枚。在管理页新建分类时也会自动建一个**同名盒子**，两边名字不用你对两遍。
  两张表的颜色跟主题走（切深色/暗黑/护眼会一起变深）。
  卡上另有两枚收尾用的（v0.99-R041）：**「🧹 清理重复的图标」** 把桌面上那些
  `X_20261011_152441` 形态的重复快捷方式收进一只 **「收纳·重复的」** 盒（盒里一份
  `清单.json` 记着原名和来源；这只盒**只进不出**，不会被搬回桌面、也不计入"没被认领"，
  要彻底清掉就打开那只文件夹自己删）；**「删所有空盒」** 一次收掉历轮攒下的空壳，
  只删空的、里面还有图标的一枚不碰，删之前逐枚点名。**撞名留在盒里的那几枚不算失败**
  （桌面上那一枚名字内容都不动，等你把它处理掉，下一次散回自己就走得通）。
- **桌面图标备份**：桌面文件打包 zip，图标意外丢失一键找回

### 🧰 系统工具（"系统"页）

- **🔒 自带锁屏**：全屏锁定画面（大时钟+四档字号），壁纸一条下拉可选
  **内置四套主题图（深色/暗黑/浅色/护眼）/ 自定义…导入自己的图 / 无**；独立密码 +
  密保找回，锁定期自动隐藏"注销"防绕过；家长模式到时同源弹锁屏
- **🖥️ 桌面系统图标（一键显隐）**："系统"页锁屏下面一枚勾选框，开关桌面上的**此电脑 / 回收站 /
  用户的文件 / 控制面板 / 网络**，等价于 Windows「个性化 → 主题 → 桌面图标设置」里那五个勾，
  不用翻系统设置；勾上就显示、取消就隐藏，框里的对勾如实反映当前状态。它同时就是「系统图标常驻」的第二个入口（与"设置→公共分类显示"里「🖥 系统图标」那枚同一个开关，两边互相回显）；点完还会把桌面布局摆回来，不再"点一下桌面变乱、再点分类才好"
- **👀 条件监视**：监视某进程的"出现/消失"自动执行动作（典型：虚拟机
  关机后自动关主机）；每 5 秒轮询，内置 2 示例+2 实用模板、可编辑、启停
  开关，触发弹窗提示；支持随"导出/导入全部数据"迁移（导入后默认停用）。
  动作是**关机/重启**时，排定之后会再问一句"现在取消吗"——点一下就撤销这次倒计时（结果在日志页如实说：取消成功／没取消掉并给出返回码／读不到结果请你核对），30 秒内没人点就照原计划执行
- **📜 事件查看器（大白话）**：把 Windows 系统日志翻译成人话（31 类映射：
  开关机/异常崩溃/服务故障/磁盘/驱动/更新…），异常红色标，双击看详情 +
  一键生成过滤脚本；"🌐 原生查看器"按当前筛选在 Windows 事件查看器生成
  自定义视图直接看；不用再啃原生事件查看器
- **📅 计划任务**：列出/运行/启停/删除 Windows 计划任务（带动作归类、
  大白话备注、创建时间），自带创建器（定时关机/重启/开软件/跑命令/
  **指定多长时间后**（一次性延时）/ **打开虚拟机**（VMware/VirtualBox，
  可多选））+ 懒人模板 7 个 + 编辑器；关机重启类二次确认+红标
- **⚡ 一键维护**：清理临时文件、清空回收站（弹窗报数）、刷新 DNS、
  重启资源管理器、刷新图标缓存、清空剪贴板、清空最近使用、磁盘清理——
  成功/失败都有弹窗与日志

## 使用速览

1. 打开"🖱️ 拖拽分类"，把桌面图标拖到右侧分类上
2. 鼠标移到屏幕顶部 → 悬浮条点分类名 → 桌面立刻切换
3. 点"全部"恢复所有图标（自动按保存的排列就位）
4. "🧰 系统"页试用锁屏/事件查看器/计划任务；"⚙️ 设置"页切主题改行为

## 系统要求

- Windows 10 / 11（文件夹"选项卡方式打开"需 Win11 22H2+，Win10 自动改多窗口）

## 启动方式

**打包版（推荐普通用户）**：解压后双击 `deskbits_beta_<版本号>.exe`（例如
`deskbits_beta_0.99-R044.exe`，包名与 exe 名跟着版本走）即可，
无需安装 Python——单文件包只有这一个 exe；单目录包进入文件夹双击
同名 exe（整个文件夹不要拆散）。

**源码版（开发者）**：装好 Python 3.14 与依赖（`pip install -r
requirements.txt`，或用 uv 建 .venv）后：

| 入口 | 说明 |
|---|---|
| 启动.bat | 日常入口（守护器拉起，崩溃自动重启）|
| 自动测试.bat | 一键自检 11 项功能（出问题先跑它）|
| 打包_Nuitka_单文件.bat / 打包_Nuitka_单目录.bat | 出发行包（zip+校验码）|
| 一键备份.bat | 打包源代码与必要内容为 ZIP（含归档笔记；不含临时/日志/生成报告，存入 backup\）|

## 首次运行提示（SmartScreen）

程序未做数字签名，个别电脑首次运行 exe 时 Windows 可能弹
"已保护你的电脑"（SmartScreen）。这是对无签名新程序的通用提醒，
与文件是否安全无关：点 **"更多信息" → "仍要运行"** 即可；
也可右键 exe → 属性 → 勾选"解除锁定"后再运行。
文件是否完整请用同一下载附带的**校验码文件**核对
（`certutil -hashfile 文件名 MD5`）。

## 数据与隐私

所有数据保存在本机 `config\` 与 `data\` 目录。分发给别人前，可在
"📦 数据管理"里一键清空图标名单、文件夹组、统计和日志；导出的备份
默认存放在程序目录 `backup\`（可在数据管理页自定义）。
